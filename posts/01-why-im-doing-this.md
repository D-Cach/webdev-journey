Learning to Code

This repository documents my journey learning web development and programming from near-zero.

I have done some coding in the past, but I did not retain much of it because I was not consistent with my learning. This time, I want to focus on understanding the fundamentals and practicing regularly.

My long-term goal is to attend vocational school in Japan for IT. I want to eventually live and build my future there, and developing useful technical skills is part of that plan.

I have previously built two web applications with the help of Claude Code and other AI tools. Those projects gave me an idea of what I could build, but I relied heavily on AI to write the code. I want to change that.

For this journey, I plan to use The Odin Project and freeCodeCamp as my main learning resources. I will also use AI as a mentor to explain concepts, review my code, and help me understand errors. I do not want the AI to write my code for me.

I expect this to take around 18–30 months because I will be learning part-time. I am not setting a specific deadline for becoming a developer. My main focus is to keep learning, practice what I learn, and build projects along the way.
